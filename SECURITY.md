# Security policy

Version 0.1 is an early evaluation release, not independently audited. Read docs/THREAT-MODEL.md before processing high-risk samples.

Report suspected vulnerabilities privately to **info@ghostlayerdefense.com**. Include the commit/version, platform/Python version, steps, expected/actual behavior, and a harmless minimal reproduction. Do not send passwords, production evidence, live malware, or session URLs. No response SLA or bug bounty is promised.

False positives and coverage requests can be public issues only after removing private information. Never label an unknown file safe because Lens did not match a rule.
